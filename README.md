# 🎮 怪物世界 - 纯单机版

纯前端H5怪物收集游戏，无需后端，打开即玩！

## ✨ 功能特性

- 📦 **纯单机游戏** - 所有数据存在浏览器localStorage
- 🎮 **完整游戏系统** - 探索、战斗、捕捉、商店、背包
- 📱 **移动端适配** - 完美支持触屏操作
- 🚀 **无需服务器** - 纯静态页面，直接部署

## 🎯 游戏内容

- 5种属性怪物（火、水、草、电、岩石）
- 10种技能，包含攻击和治疗技能
- 3个探索区域，不同难度
- 4种道具（药水、捕捉球）
- 完整的战斗系统

## 🚀 运行方式

直接在浏览器打开 `index.html` 即可开始游戏！

## 🛠️ 技术栈

- React 18 + TypeScript
- Vite 构建工具
- Zustand 状态管理
- Tailwind CSS 样式
